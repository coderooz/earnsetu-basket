# Glossary — EarnSetu Basket

| Term | Meaning |
|------|---------|
| **EarnSetu** | The parent ecosystem — a planned multi-platform hyperlocal-commerce "Economic Operating System". |
| **EarnSetu Basket** | This application — the shopping-list and purchase-recording client. |
| **Basket** | Shorthand for EarnSetu Basket. |
| **Shopping list** | A named collection of items a user intends to buy. |
| **Item** | A single planned purchase within a list (name, quantity, unit, note, status). |
| **Purchase** | A record of what was actually bought (actual quantity, price, time); may be partial. |
| **CNG** | Continuous Native Generation — Expo generates `ios/` and `android/` from config rather than committing them. |
| **EAS** | Expo Application Services — cloud build/submit/update service (not configured here). |
| **OTA update** | Over-the-air JS/asset update via `expo-updates` (installed, unused). |
| **NativeWind** | Tailwind-CSS-for-React-Native library used for styling. |
| **ADL** | (Not used here.) |
| **ADR** | Architecture Decision Record — a dated, durable record of a significant decision. |
| **PRI** | Project Reference Index — a governance reference index of the repo structure (`.workspace/PRI/`). |
| **LFI** | Logic Flow Index — a governance reference index of behavioural flows (`.workspace/LFI/`). |
| **Offline-first** | Architecture where local storage is the primary source of truth and the app works without connectivity. |
| **Sync** | Reconciling local changes with a remote store. |
| **Tombstone** | A marker recording a deleted record so deletion can propagate. |
| **Scaffold / prototype** | A project skeleton with structure but little or no implemented product functionality. |
| **Stub / placeholder** | Non-functional code (or an empty file) indicating intended work. |
| **IMPLEMENTED / NOT_IMPLEMENTED / PARTIALLY_IMPLEMENTED** | Evidence-based feature status labels (see [`FEATURE_STATUS.md`](FEATURE_STATUS.md)). |
